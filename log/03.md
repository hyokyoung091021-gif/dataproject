오늘 결정한 것: 데이터
AI에게 보낸 프롬프트: 공공도서관 통계 데이터를 활용해 데이터 과학 탐구를 하려고 한다. 회귀분석, 분류, 군집화, 연관 분석 중 적절한 분석 방법을 선택하고, 구체적인 탐구 질문과 활용할 데이터를 추천해 줘.
AI가 준 것 중 고치거나 버린 것과 그 이유: AI가 추천해준 데이터는 수행 조건에 맞지 않아서 버렸다.
느낀 점: AI가 제안한 군집화 방법과 탐구 주제는 유지하되, 실제 데이터로 확인하지 않은 도서관 유형을 분석 결과처럼 제시한 부분은 수정하였다. 또한 데이터의 항목과 수를 직접 확인하기 전에는 기준에 적합하다고 단정할 수 없으므로, 실제 데이터의 행과 열, 수치형 항목을 확인한 뒤 최종적으로 결정했다.
